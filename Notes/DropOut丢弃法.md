# DropOut丢弃法

# 为什么需要DropOut

- 一个好的模型需要对输入数据的扰动鲁棒：不管加入多少噪音，图片中的内容始终都是能够看清除的

  <img src="https://typora-alex2.oss-cn-shanghai.aliyuncs.com/202605202220540.png" alt="image-20260520222018470" style="zoom:50%;" />

- 正则项的作用就是使得权重不要过大，避免过拟合

- 在数据中加入噪音等价于一个正则

- 丢弃法是在层之间加入噪音，丢弃法其实是一个正则

# 无差别的加入噪声

- 假设x是上一层到下一层的输出

- 对x加入噪音后得到$x'$，我们希望**加入噪声后不要改变x的期望**(无偏估计)

- 丢弃法：对于x’，给定一个概率p，在p的概率中将真实的原始输入变成0（此时p为丢弃概率，1-p为保留概率），在其它的地方除以一个（1-p），即将该输入变大。在一部分地方以一定的概率p变成0，在另外一部分地方以一定的概率变大，所以它的期望是不变的（对x'来说，有p成概率变为0,1-p成概率变为$\frac{x_i}{1-p}$）
  $$
  E[x_i']=p * 0 +(1-p)*\frac{x_i}{1-p}=x_i
  $$
  <img src="https://typora-alex2.oss-cn-shanghai.aliyuncs.com/202605202225989.png" alt="image-20260520222553959" style="zoom:50%;" />

## 推理阶段

<img src="https://typora-alex2.oss-cn-shanghai.aliyuncs.com/202605202231560.webp" alt="img" style="zoom:50%;" />

- 在预测的过程中因为不训练，所以不使用dropout
- 正则项只在训练中使用，它只会对权重产生影响，在预测的时候，权重不需要发生变化的情况下，不需要正则，所以在推理中不需要正则（$h=dropout(h)=原本的输出），确保在推理过程中能够有一个确定性的输出

> 在Hinton提出DropOut时， 他将Dropout定义为集成方法。每一次激活的隐藏层神经元个数不一样（这一次激活3个神经元，下次激活2个神经元）。
>
> <img src="https://typora-alex2.oss-cn-shanghai.aliyuncs.com/202605202236570.png" alt="image-20260520223606529" style="zoom:50%;" />
>
> **例子**
>
> 输入只有两个特征：$x=[x_1,x_2]$，隐藏层有 2 个神经元：A和B。设：A = $x_1$,B = $x_2$，$w_A=2,w_B=4$,则$y=2x_1+4x_2$，p=0.5
>
> - 第一次训练forward模型（A存在[$m_A=1$])，B关闭[$m_B=0$]，发生的概率为p(1-p)=0.25）：$y_1=2x_1$
> - 第二次训练forward模型（A关闭[$m_A=10$])，B存在[$m_B=1$],发生的概率为p(1-p)=0.25）：$y_1=4x_2$
> - 第三次训练forward模型（A存在[$m_A=1$])，B存在[$m_B=1$],发生的概率为p(1-p)=0.25）：$y_1=2x_1+4x_2$
>
> 测试时使用完整网络$y=2x_1+4x_2$​,但需要做缩放。训练时：每个神经元保留概率p=0.5。训练输出时，$y=m_A*2x_1+m_B*4x_2$​，对其求期望
> $$
> E[y]
> =
> 0.5(2x_1)+0.5(4x_2)
> 
> =x_1+2x_2
> $$
> 刚好等于：所有 dropout 子网络输出的平均,也就是$\sum_{\text{m}} P(m) y(m)=0.25*2x_1+0.25*4x_2+0.25*(2x_1+4x_2)=x1+2x_2$
>
> 因此测试阶段本质是所有子网络预测的平均

> 要么训练时除以 1-p（inverted dropout），要么测试时再乘以 1-p（相当于是对各个子网络的预测值取平均），二者至少其一必须有。假设测试时需要乘以 1-p 但是未乘，通过 dropout 方法训练出来的模型在预测的时候没有通过 mask 掩码，使用整个模型输出会与真实值差距很大。
>
> **例子**
>
> - 一个神经元输出 = **100**
> - 保留 概率 1-p = **0.5**（保留一半，关掉一半）
>
> ------
>
> **情况 1：训练时（开启 dropout）**
>
> 随机关掉 50% 神经元。
>
> 所以这个神经元**只有 50% 概率参与计算**。
>
> 训练时的**平均输出** =
>
> 100 × 0.5 = **50**
>
> ------
>
> **情况 2：测试时（关闭 dropout，全开）**
>
> 神经元 100% 工作。
>
> 输出 = **100**
>
> ---
>
> 那么，训练时平均输出：**50**
>
> 测试时直接输出：**100**
>
> **差了整整 2 倍！**
>
> ---
>
> **解决方法**
>
> ## 方法 1：测试时乘以 1-p（原始 dropout）
>
> 测试输出 = 100 × 0.5 = 50
>
> ✅ 训练 = 测试，对齐了
>
> ## 方法 2：训练时除以1-p（inverted dropout，现在用的）
>
> 训练时：100 × (mask /1-p)
>
> 平均输出 = 100 × (0.5 / 0.5) = 100
>
> 测试时直接输出 100
>
> ✅ 训练 = 测试，也对齐了

# 代码

```python
# 实现以dropout的概率丢弃张量输入x中的元素
import torch
from torch import nn
from d2l import torch as d2l

def dropout_layer(X, dropout):
    assert 0 <= dropout <= 1
    if dropout == 1:
        return torch.zeros_like(X)
    if dropout == 0:
        return X
    mask = (torch.rand(X.shape) > dropout).float()	# 筛选除值比dropout大的矩阵元素
    # torch.rand:生成【0,1】的均匀分布
    return mask * X / (1.0 - dropout)
  # 如果将mask*x 改为X[mask]会降低处理速度，乘法远远比选元素要快
  
```

# QA

1. dropout随机置0对梯度和反向传播的影响是什么？

   如果神经元被随机置0，那么该神经元的梯度也会变为0，此轮神经元对应的权重就不会被更新。没有置0的地方会被乘一个系数（$\frac{1}{1-drop_out}$）,神经元对应的权重会被更新。因此在求梯度方面可以把dropOut看成是一个对称函数。

2. 丢弃法的丢弃依据是什么？如果丢弃不合理对输出的结果影响会很大吗？

   可以吧p看出一个正则化项。丢弃不合理意味着p设置的不合理，要么太小，对模型的正则效果不好，还是会过拟合；要么太大，会拟合。因此是个可以调整的超参数

3. Dropout 随机丢弃，如何保证结果的正确性和可重复性？

   正确性没办法保证，机器学习只考虑模型效果。可重复性可以通过随机种子来设置，同时需要禁掉cudnn，因此并行运算会导致每次矩阵乘法或加法顺序不一样会导致结果不一样

4. 丢弃法是每次迭代一次，随机丢弃一次吗？

   每一个隐藏层进行前向传播的时候调用一次丢弃法，随机丢一次。如果有三个隐藏层，就会用三个dropOut layer，就是随机丢弃三次。

5. 在使用BN的时候，还有必要使用dropOut吗？

   BN是给卷积神经网络用的，dropOut是给全连接层用的。所以，BN和Dropout没有关系。

6. dropOut会不会让训练的loss曲线方差变大啊，不够平滑？

   有时候会测了10个batch数据画一次曲线，抖动大的现象会存在，但可以不用care。因为曲线一开始不平滑后面都得平滑。如果最后不平滑就代表不收敛。

7. 为什么推理中的dropOut是直接返回输入

   预测是不对权重进行更新，因此不需要DropOut。DropOut是一个正则项，作用是在更新权重的时候，降低模型复杂度。而推理的时候是不需要对模型进行调整，不需要DropOut。也可以开DropOut，但需要多进行推理几次（此时只对一个样本进行推理），把结果的方差降低，提高预测的稳定性。训练过程中会逐个batch进行很多轮的训练，模型的稳定性可以实现的。

8. dropout函数返回值的表达式return X*mask/（1.0-p）没被丢弃的输入部分的值会因为表达式分母（1-p）的存在而改变，而训练数据的标签还是原来的值，这怎么理解？

   dropOut唯一改变的只有隐藏层的输出（而不是输出层的输出）

9. 训练时使用dropout，推理时不用。那会不会导致推理时输出结果翻倍？比如dropOut=0.5，推理时输出结果是训练时2个子神经网络的叠加而翻倍？

   训练时结果没有变为0的神经元的输出结果会乘2，因此不会出现推理输出结果是训练时的两倍

10. dropOut每次随机选几个子网络，最后做平均的做法是不是类似于随机森林多决策树做投票的这种思想？

    是的，但DropOut更像正则项。

11. 在解决过拟合问题上，dropOut和regularization的主要区别是什么？

    dropOut可以看成一个regularization，但跟l2 regularization是两种不一样的过拟合。L2（$L = L_{data} + \lambda \sum_i w_i^2$）是处理参数过大导致的过拟合,本质上是让模型变平滑，让决策边界不那么复杂，同时对输入扰动不敏感

    > - 没有 L2,模型可能选择w=[1000,0.001]
    >
    > - 有 L2,模型更倾向w=[1,1]
    >
    > 因为L2正则化项：$1^2+1^2 \ll 1000^2$
    >
    > 所以**L2是在“压缩模型复杂度**

    dropOut处理 神经元之间“共适应”导致的过拟合。因此，训练时会随机删除神经元，让每个神经元必须学会“独立工作”

    > - 神经元A：检测耳朵
    > - 神经元B：检测尾巴
    > - 神经元C：检测胡须
    >
    > 训练过程中:C 发现“反正A和B总会出现，我只要依赖它们即可。”于是C 不再学习独立特征，此时网络形成“固定合作关系”。一旦测试数据略微变化：比如耳朵挡住了或者尾巴缺失了，整个组合立刻失效，这也是过拟合。

12. dropOut层丢弃的是前一层还是后一层？

    可以看出DropOut丢弃的是前一层的输出，也可以看成丢弃后一层的输出。这两个是一个意思

13. dropOut和权重衰减都属于正则化，两者有什么区别？

    dropOut适用于全连接层，而weightDecay适用于所有网络，比如卷积层等，因此WeightDecay更加常用。但DropOut更好调参，p值调参更加直观（基本上就是在0.1/0.5/0.9三个值中选择），p值代表丢弃某层神经元的比例；而$\lambda$值不好调参

14. 改标签是一种mask吗？

    不是

15. dropOut的介入会不会造成参数收敛更慢，需要比没有DropOut的情况下适当调大lr吗？

    dropOut会有可能会让收敛变慢，每次更新梯度的神经元比没有DropOut时的少。lr会对期望和方差敏感，但是DropOut不会改变期望。

    > lr为什么会对期望和方差敏感？
    > $$
    > \theta_{t+1}=\theta_t-\eta g_t
    > $$
    > 
    >
    > 其中：
    >
    > - $\eta$：learning rate
    > - $g_t$：当前batch梯度
    >
    > 但由于 mini-batch 是随机采样，所以：$g_t$不是固定值,而是随机变量。因此，梯度具有均值（期望）和方差。
    >
    > 设真实全数据梯度$\nabla L(\theta)$，而mini-batch梯度$g_t$,则$E(g_t)=\bigtriangledown L(\theta)$，则mini-batch梯度的期望是真实梯度。由于每个 batch 不同：不同 batch 的梯度会波动。因此：$Var(g_t)\ne0$。梯度更新中，更新量$\triangle \theta =-\eta E(g)$，所以若梯度期望很大，如果不对$\eta$进行调整，就会更新太大，直接跳过最优点。因此learning rate 必须与梯度均值尺度匹配。
    >
    > 而梯度实际上是$g_t=E(g)+\epsilon_t$,其中$\epsilon_t$为随机噪声。因此$\triangle \theta=-\eta(E(g)+\epsilon_t)=-\eta E(g)-\eta\epsilon_t$，因此$Var(\triangle \theta)=\eta^2 Var(g)$,因此learning rate 是平方放大方差

# 总结

- 常用在多层感知机的隐藏层输出上，就是对应的全连接层的隐藏层输出上，很少会用在CNN这类的模型上面

  > 随机把特征图里**零散像素置 0**，等于强行破坏图像局部连续性、边缘纹理结构、空间位置关联，会直接造成
  >
  > 特征失真、梯度紊乱、提取到无效噪声特征，精度大幅下降。
  >
  > 而图像任务依赖**局部空间连续性、边缘、纹理、位置信息**，因此需要保证同一通道内所有空间位置**特征强相关、连续、有空间结构**。

- p经常取值为**0.1,0.5, 0.9**
